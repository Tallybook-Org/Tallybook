# Tallybook
Tallybook is settlement bookkeeping for services that charge per HTTP request - APIs paid by AI agents and other machines over Stellar, using the x402 protocol, MPP charge mode, or MPP payment channels.

## Documentation

- [Operator runbook](docs/operator-runbook.md) - operational notes for deploying and running the on-chain and off-chain pieces, including known hazards worth knowing before you hit them yourself.
